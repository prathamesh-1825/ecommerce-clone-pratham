# 🛒 Shop with Pratham

A modern, visually appealing e-commerce frontend web interface. This project is built entirely from scratch using foundational web technologies to demonstrate a strong understanding of UI design, layout structures, and responsive web principles.

## 🚀 Features

*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing using CSS Media Queries.
*   **Modern UI/UX:** Clean, intuitive, and pixel-perfect user interface.
*   **Advanced Layout Techniques:** Extensive use of CSS Flexbox and Grid for structured and organized page layouts.
*   **Interactive Elements:** CSS hover effects and smooth transitions for an engaging user experience.
*   **No Frameworks:** Pure custom CSS written from scratch without relying on external styling libraries.

## 💻 Tech Stack

*   **HTML5:** Semantic structuring of web pages for better accessibility and SEO.
*   **CSS3:** Advanced styling, animations, and responsive design.
